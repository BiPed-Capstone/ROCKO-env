## Goal and success criteria

The owner, away from the robot: "work on the next group of tasks that can be done without the robot
... code cleanup, architecture improvements, repo improvements, cleaning up old documentation,
cleaning up and removing old files". Each batch is done when:

1. Every file it removes is referenced by nothing that builds, launches or tests (checked by
   `git grep` before removing).
2. The ladder is green after it: `tools/run_ladder.sh --clean` (Tiers 0 to 3, host tests, hook tests,

4. Nothing gated is touched (no gains, no version pins, no guardrail files, no safety behavior).
